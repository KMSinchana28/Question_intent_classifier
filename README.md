# Question Intent Classification using Machine Learning

## Project Description
This project classifies user questions into different intent categories using Natural Language Processing and supervised machine learning.

## Intent Categories
- Definition
- How-To
- Reason
- Fact
- Comparison
- Yes/No

## Technologies Used
- Python
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression
- Streamlit

## How to Run
1. Install dependencies using requirements.txt
2. Run train_model.py to train the model
3. Run app.py using Streamlit

## Applications
- Chatbots
- Virtual Assistants
- Customer Support Systems
